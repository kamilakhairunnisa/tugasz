# Undangan Pernikahan Erinazzahra & Myung Jaehyun

Tanggal: 30 September 2026

## Cara memakai
1. Buka `index.html` di browser untuk melihat desain.
2. Sebelum dibagikan, upload folder ini ke hosting statis seperti GitHub Pages, Netlify, atau Vercel.
3. Setelah mendapat URL publik, buka `index.html` dan ubah:
   `const invitationUrl = "https://example.com/erinazzahra-myung-jaehyun";`
   menjadi URL website publik kamu.
4. Upload ulang. QR Code otomatis akan mengarah ke URL tersebut.

## Catatan
QR Code tidak bisa dibuat mengarah ke file lokal komputer karena HP orang lain tidak dapat mengakses file lokal tersebut.
